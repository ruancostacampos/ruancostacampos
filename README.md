# Olá, eu sou Ruan Costa 👋

**Desenvolvedor Full Stack | Angular • Next.js • Node.js • TypeScript**

Sou um desenvolvedor Full Stack focado em construir soluções web eficientes, escaláveis e com alto impacto real. Atualmente, divido minha atuação entre produtos de gestão clínica e plataformas SaaS, participando desde a concepção do banco de dados até a interface do usuário. 

Minha principal motivação é resolver problemas arquiteturais e de negócio — seja refatorando sistemas legados, garantindo a compatibilidade de hardwares limitados via WebSockets, ou otimizando a experiência de milhares de usuários diários.

### 🚀 O que eu trago para a mesa:
- **Experiência com alta demanda:** Desenvolvimento de funcionalidades críticas para sistemas usados por mais de 3.000 pacientes diariamente.
- **Ecossistema JavaScript/TypeScript:** Domínio de ponta a ponta, utilizando Angular, React, Next.js no Front-end e Node.js/Prisma no Back-end.
- **Decisões de Arquitetura:** Autonomia para escolher a melhor ferramenta para o problema, como o uso de JS puro + WebSockets para chamadores de TV em recepções médicas.
- **Trabalho Remoto & Internacional:** Experiência com comunicação técnica em inglês e fluxos ágeis de versionamento (Git Flow).

## 🌟 Projetos em Destaque

### 📌 [O Arquivo Particular](https://www.oarquivoparticular.com.br/) *(Projeto Pessoal)*
Plataforma de publicação digital desenvolvida como experimento de arquitetura focada em Backend-as-a-Service (BaaS).
* **Tecnologias:** Supabase, regras de banco de dados (Row Level Security).
* **Destaque:** Toda a lógica de negócios, autenticação e restrições de acesso foram implementadas diretamente nas regras e policies do banco de dados no Supabase, garantindo segurança nativa sem a necessidade de um backend tradicional intermediário.

### 📌 Sistemas de Gestão Clínica (Hipersoft e Maxclin) *(Profissional)*
Plataformas de gestão clínica, prontuário eletrônico e triagem.
* **Impacto:** Sistemas críticos utilizados no atendimento de mais de 3.000 pacientes/dia por cerca de 30 profissionais.
* **Destaque:** Implementação de um chamador de TV em tempo real via WebSocket. Optei por usar HTML/JS puros, fora do stack principal em Angular, garantindo máxima performance e compatibilidade com navegadores nativos de Smart TVs mais antigas.

### 📌 ReporteAqui *(Profissional)*
Plataforma SaaS de canal de denúncias corporativas.
* **Tecnologias:** Next.js 16, TypeScript, PostgreSQL, Prisma 7, Tailwind CSS v4.
* **Destaque:** Atuação Full Stack de ponta a ponta, desde a modelagem de dados e migrations no PostgreSQL até a criação das rotas de API e componentes de interface.

### 📌 [Terráquea](https://terraquea.com.br/)
Página de pré-lançamento (Coming Soon) imersiva para marca de produtos naturais.
* **Tecnologias:** JavaScript, Three.js, GSAP, HTML, CSS.
* **Destaque:** Foco em engenharia de UI e UX avançada. Desenvolvimento de uma experiência interativa utilizando **Three.js** para renderização de elementos 3D no navegador e **GSAP** para orquestrar animações fluidas e de alta performance, com o objetivo de capturar a atenção e gerar engajamento antes do lançamento oficial.

### 📌 [FantasticaPay](https://fantasticapay.com.br/) *(Freelance)*
Plataforma de pagamentos digitais.
* **Destaque:** Desenvolvimento Front-end focado em fluxos de checkout seguros, alta conversão e responsividade para diferentes dispositivos.
